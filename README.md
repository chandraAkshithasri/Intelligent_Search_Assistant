Intelligent Search Assistant Using Machine Learning

Project Overview

This project develops an intelligent search assistant using Machine Learning and TF-IDF with cosine similarity to find relevant documents for user queries.

Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity
- Google Colab

Features

- Loads and processes a knowledge base.
- Searches for relevant documents based on user queries.
- Evaluates search performance using validation accuracy.
- Generates a submission CSV file.

Results

Validation Accuracy: 67.86%

Files

- "Intelligent_Search_Assistant.ipynb" — Project code
- "accuracy_graph.png" — Accuracy graph
- "machine-deep-learning.zip" — Dataset
- "submission.csv" — Generated predictions

How to Run

Open the notebook in Google Colab and run the cells in order.
